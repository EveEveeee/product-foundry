# 实现来源与证据

项目作者与产品负责人：王洋娟。公开资料整理日期：2026-10-11。

## 贡献与实现来源

我负责当前产品方向、范围和流程决策、交互规则、阶段任务与验收条件，并借助 Codex、Pi 等 AI 编码工具推进实现、检查结果和修复。以下已有基础与历史贡献分别保留归属。

| 部分 | 已有基础 | 本案例展示的工作 |
| --- | --- | --- |
| 桌面工作台 | [AionUi](https://github.com/iOfficeAI/AionUi)、[AionCore](https://github.com/iOfficeAI/AionCore) 及周承健维护的历史定制版本 | 后续团队模型配置与创建异常修复、模型比较交互与恢复规则、产品工坊品牌及主题更新；以 AI 协作方式推进实现和验收 |
| 需求规划原型 | [Agent Blueprint](https://github.com/hubooooooo/agent-blueprint)，上游作者 Hubo；既有推导引擎、参考组件及规划方法 | 新增个人需求规划范围，设计决定追溯、阶段 Prompt、文档版本与确认规则，推进独立网页工作台与后端联调 |
| 审查 Agent POC | Pi 运行时、MCP 协议与 SDK、配置的模型服务 | 限定资料的审查流程、工具契约、校验与建议提交机制、失败／缺证据／预算规则及案例验证 |

17 个 Harness 参考组件属于上游基础，不表示全部已接入，也不计为本人从零原创。桌面已有会话和助手等基础能力、历史模型比较实现，与本人后续产品优化分开描述。本公开仓库不分发实现源码；实现仓库中的第三方许可证和版权通知仍应保留。

三部分尚未统一运行入口、接口与数据。历史名称“初造”“Idea Foundry／创意铸造厂”对应需求规划原型，不另算一个上线产品。
